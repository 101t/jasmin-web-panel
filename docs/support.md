# Support & Community

## Get Help

If you encounter issues or have questions:

- **Telegram Group**: [Join our community](https://t.me/jasminwebpanel)
- **GitHub Issues**: [Open a ticket](https://github.com/101t/jasmin-web-panel/issues)

## Contributing

We welcome contributions from the community!

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes.
4. Submit a Pull Request.

Read the [contributing guide](https://github.com/101t/jasmin-web-panel/blob/master/CONTRIBUTING.md) for the
development setup and how to run the unit and integration tests.
